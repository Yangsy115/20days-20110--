# [보기쉬운 가챠분석]
## 소개
이 프로그램은 명일방주라는 게임에 불편한 현재스택확인이 없는걸 프로그램으로 만들어
현재스택과 스택에맞는 6성이 나오는 확률을 계산하는프로그램이다.
## 핵심 기능
- 확률 계산 로직: 구간별 확률 변동 시스템을 구현
- 결과 출력: 현재 스택과 최종 확률을 한눈에 보기 쉬운 형태로 콘솔에 출력
- 스택 입력 처리: 실수로 문자열, 특수기호, 또는 음수를 입력해도 재입력을 유도
## 사용한 개념
- 구조체: 뽑기와 관련된 데이터인 현재 스택과 최종 확률을 하나의 의미 있는 단위로 묶어서 관리하기 위해 사용
- 포인터: 메모리의 안전성을 위해 전역 변수를 피하고자 사용
## 실행 방법
1. 컴파일: gcc main.c -o gacha_calc
2. 실행: ./gacha_calc
## 만들면서 배운 점
C언어의 포인터 개념을 활용하여 함수 간에 데이터의 값을 수정하는 연산자 활용하는 논리를 이해하는 과정이 가장 까다로웠다.
단순히 편한 전역 변수를 쓰기보다, main 함수 안에 안전한 지역 변수를 두고 주소로 넘겨주는 방식으로 코드를 설계하여 코드가
꼬이는일을 방지하고 구조체와 포인터대해 자세히 배웠다.

# [프로젝트 이름]
## 소개
캐릭터의 이름을 짓고 스탯이 랜덤으로 정해지며 레벨업을 하여 변화하는 스탯을 볼 수 있는 프로그램이다.

- 레벨업 시스템

## 실행 방법
1. 컴파일: gcc main.c -o character
2. 실행: ./character
